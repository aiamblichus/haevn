## Where your data is stored

HAEVN stores everything locally in your browser. HAEVN runs no servers of its own. It has no accounts and no cloud storage.

| What | Where |
|---|---|
| Conversation data and metadata | IndexedDB (browser storage) |
| Search index | IndexedDB |
| Media files (images, documents, audio, video) | Origin Private File System (OPFS) |
| Extension settings, including AI endpoint URLs and API keys | `chrome.storage.local` |

## What leaves your machine

HAEVN is built so that nothing leaves your machine without your consent. The list below is every case where data does leave it.

1. **The AI platforms you sync from.** Syncing reads a chat from the platform you are signed in to, using your browser session. HAEVN reads from the platform. It does not write to it. Images and files are downloaded from the platform's file servers. If a download fails, HAEVN keeps the link. The viewer and bulk exports then fetch the file from that link.

2. **An AI metadata endpoint, if you turn it on.** This is off by default. With AI metadata on and a URL set, HAEVN sends one request per chat that needs metadata, to `{URL}/chat/completions`. The request contains:
   - the chat's title and its platform name;
   - an excerpt of the messages: the text of user and assistant messages, including thinking text where the platform kept it.

   Chats of up to 50 messages go in whole, up to the size limit. Longer chats are sampled from the main thread and from side branches. Each message is cut at 1,000 characters, and the excerpt stops at about 15,000 characters. Images, files and tool calls are not sent. If you enter an API key, it is sent as a bearer token.

3. **A starmap embeddings endpoint, if you turn it on.** This is off by default. It runs only when AI metadata, starmap and embeddings are all on, and an endpoint and a model are set. HAEVN sends batches of up to 10 chats to `{URL}/embeddings`. The input for each chat is its metadata: title, description, synopsis, categories and keywords, whether you wrote them or the AI did. The conversation text itself is not sent, but the metadata summarises it.

4. **Your own machine.** The CLI talks to a daemon on `localhost`. That traffic stays on your machine.

HAEVN has no default AI endpoint. You set the URL, and the key if the endpoint needs one.

## API keys

The API keys you enter for the AI metadata and embeddings endpoints are stored in `chrome.storage.local`, the extension's local storage. The CLI key is stored there too. The keys are not encrypted, so anyone with access to your browser profile can read them.

HAEVN does not store your login to any AI platform. When you sync, it uses your browser's existing session.

## Storage limits

Chrome's storage quotas apply:

| Storage type | Typical quota |
|---|---|
| IndexedDB | ~50MB per extension (configurable) |
| OPFS | ~600MB+ (device dependent, much larger) |

Media files are stored in OPFS specifically because it supports much larger files than IndexedDB. Text content, metadata, thumbnails, and the search index all live in IndexedDB.

<Aside type="tip">
  Check your current OPFS usage by running `haevnDebug.opfs.usage()` in the Options page console.
</Aside>

## What HAEVN accesses

When syncing, HAEVN uses your existing browser session (cookies) to access the AI platform you're on. It makes the same API calls that the platform's own website would make. It relies entirely on your browser's existing authentication.

## Backing up your data

Because everything is local, **if you uninstall the extension or clear your browser data, your archive is gone**. To prevent data loss:

- Run `haevn backup` to keep a complete copy of your archive in a folder you choose. See [Backup and Restore](/user-guide/backup-restore/)
- Use [Export All](/user-guide/export/) to download a HAEVN ZIP export, for moving, reading or sharing. It can be re-imported into HAEVN on any machine, but not exactly as it was

## Clearing your data

To delete all HAEVN data:

1. Uninstall the HAEVN extension from Chrome
2. Chrome will prompt you whether to also delete the extension's stored data — choose "Yes"

Or, to clear data while keeping the extension installed, use the archive's bulk delete feature to remove individual conversations, or run `haevnDebug.db.delete()` and reinstall the extension.
