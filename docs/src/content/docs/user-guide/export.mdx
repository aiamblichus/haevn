HAEVN supports multiple export formats.

## Export formats

- **HAEVN Archive (.zip)** — an export of your chats with media and a manifest, for moving, reading and sharing. It is not a backup: for backups, see [Backup and Restore](/user-guide/backup-restore/).
- **HAEVN JSON (.json)** — single-chat canonical JSON export.
- **HAEVN Markdown (.md)** — single-chat readable transcript export.
- **Pi Session (.jsonl)** — single-chat export for Pi-compatible session files.

<Aside type="note">
  Multi-chat exports currently use **HAEVN Archive (.zip)**. JSON, Markdown, and Pi exporters are single-chat.
</Aside>

<Aside>
  CLI exports also use these exporters, but are intentionally limited to single-chat + no-media payload transfer.
</Aside>

The archive ZIP includes:

- `manifest.json` (export metadata + index)
- `chats/*.json` (canonical HAEVN chat records)
- `media/**/*` (staged media assets when present)

## Exporting a single conversation

**From the Archive:** Click **Export** on any conversation row, choose an export format, then confirm.

**From the Viewer:** Click the **Export** button in the viewer toolbar.

**From Search results:** Click **Export** on any search result row.

## Exporting multiple conversations

To export a selection of conversations:

1. In the Archive, use the checkboxes to select the conversations you want.
2. Click **Export Selected** in the toolbar.
3. Confirm export (multi-chat exports are packaged as HAEVN ZIP).
4. HAEVN generates a ZIP file containing canonical chat JSON and extracted media files.

## Exporting your entire archive

Click **Export All** in the Archive toolbar to download an export of your whole archive as a ZIP file. For large archives, ZIP generation runs in the background — the download will start automatically when it's ready.

<Aside type="tip">
  **Backing up your archive:** use `haevn backup`, not Export All. An export moves your conversations to another machine or tool, but re-importing it does not put them back exactly as they were. The [Backup and Restore](/user-guide/backup-restore/) page covers the backup and how to restore it. The archive ZIP can still be re-imported on another machine with the [Import](/user-guide/import/) feature.
</Aside>

## What's included in exports

| Content | HAEVN Archive ZIP | HAEVN JSON | HAEVN Markdown | Pi Session JSONL |
|---|---|---|---|---|
| All messages | ✅ | ✅ | ✅ | ✅ |
| Timestamps | ✅ | ✅ | ✅ | ✅ |
| Platform metadata | ✅ | ✅ | ✅ | Partial |
| Attachments/media | ✅ | Inline/encoded references | Placeholder/link references | URLs + binary placeholders |
| Thinking blocks | ✅ | ✅ | ✅ | ✅ |
| Tool calls | ✅ | ✅ | ✅ | ✅ |
| Conversation branches | ✅ | ✅ | Current selected path | Current selected path |
| Canonical manifest | ✅ | ❌ | ❌ | ❌ |

<Aside>
  Pi Session export prioritizes interoperability and is currently lossy for embedded binary media.
</Aside>
