HAEVN currently exports conversations as a **HAEVN archive ZIP** (canonical backup format).

## Export format

<Aside type="note">
  Export plugin support is being expanded. Right now, the extension uses a single exporter: **HAEVN Archive (.zip)**.
</Aside>

The archive ZIP includes:

- `manifest.json` (export metadata + index)
- `chats/*.json` (canonical HAEVN chat records)
- `media/**/*` (staged media assets when present)

This is the recommended **lossless backup format** for restore/import across machines.

## Exporting a single conversation

**From the Archive:** Click **Export** on any conversation row, then confirm the export. The HAEVN archive ZIP downloads when ready.

**From the Viewer:** Click the **Export** button in the viewer toolbar.

**From Search results:** Click **Export** on any search result row.

## Exporting multiple conversations

To export a selection of conversations:

1. In the Archive, use the checkboxes to select the conversations you want.
2. Click **Export Selected** in the toolbar.
3. Confirm export.
4. HAEVN generates a ZIP file containing canonical chat JSON and extracted media files.

## Exporting your entire archive

Click **Export All** in the Archive toolbar to download your complete archive as a ZIP file. For large archives, ZIP generation runs in the background — the download will start automatically when it's ready.

<Aside type="tip">
  **Backing up your archive:** Use Export All periodically. The resulting HAEVN archive ZIP can be re-imported into HAEVN on another machine using the [Import](/user-guide/import/) feature.
</Aside>

## What's included in exports

| Content | HAEVN Archive ZIP |
|---|---|
| All messages | ✅ |
| Timestamps | ✅ |
| Platform metadata | ✅ |
| Attachments/media | ✅ |
| Thinking blocks | ✅ |
| Tool calls | ✅ |
| Conversation branches | ✅ |
| Canonical manifest | ✅ |

<Aside>
  The extension export path currently uses the HAEVN archive exporter only. Additional exporters (JSON file, Markdown, Pi session JSONL) are planned.
</Aside>
