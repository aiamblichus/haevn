HAEVN can import conversations from external sources — useful for seeding your archive with existing exports before you start using the sync extension, or for bringing in an archive export from another machine. To put back a backup made with `haevn backup`, see [Backup and Restore](/user-guide/backup-restore/).

## Supported import formats

| Source | Format | How to get it |
|---|---|---|
| **ChatGPT** | ZIP file | Settings → Data controls → Export data |
| **Claude Code** | JSONL file | Local session files in your `.claude/` directory |
| **Codex** | JSONL file | Local session files in your `.codex/sessions/` directory |
| **PI** | JSONL file | Local session files in your `.pi/sessions/` directory |
| **OpenRouter** | JSON file | An OpenRouter chatroom export; every chatroom in it is imported as a chat (see the [OpenRouter page](/platforms/openrouter/)) |
| **HAEVN archive export** | ZIP | Export All in the Archive, or a multi-chat export |
| **HAEVN Markdown** | `.md` | YAML-frontmatter markdown transcript |
| **Fragments** | `.md` | Recovered chats with no online copy, one Markdown file each, imported from the terminal (see [Fragments](/user-guide/fragments/)) |

<Aside>
  Claude Code, Codex, PI, and OpenRouter are import-only providers right now (no live sync). For Claude Code details, see the [Claude platform page](/platforms/claude/).
</Aside>

## How to import

<Tabs>
  <TabItem label="Options UI">

<Steps>
1. Open the archive (click **Archive** in the HAEVN popup, or right-click the extension icon → **Options**).

2. Click the **IMPORT** button in the archive toolbar.

3. In the import dialog, click **Choose file** and select your ZIP or JSON export file.

4. Click **Import**. HAEVN processes the file and adds the conversations to your archive.

5. The search index rebuilds automatically once the import completes.
</Steps>

  </TabItem>
  <TabItem label="CLI">

```bash
# Claude Code
haevn import --format claude_code ~/.claude/projects/my-proj/session.jsonl

# Codex
haevn import --format codex ~/.codex/sessions/2026/03/23/rollout-...jsonl

# PI
haevn import --format pi ~/.pi/sessions/2026-03-23T14-48-43-844Z_...jsonl

# OpenRouter chatroom export (one file, many chats)
haevn import --format openrouter ./open-router-chats.json

# HAEVN Markdown
haevn import --format markdown ./conversation.md
```

Useful flags: `--no-overwrite` to skip existing chat IDs, and `--skip-index` to skip index rebuild after import.

  </TabItem>
</Tabs>

## Importing from ChatGPT

ChatGPT's native export format is a ZIP file containing your full conversation history. To export from ChatGPT:

<Steps>
1. Go to [chatgpt.com](https://chatgpt.com) and open **Settings**.

2. Navigate to **Data controls** → **Export data**.

3. Click **Export** and wait for the email with your download link (this can take several minutes to hours depending on your history size).

4. Download the ZIP file from the link in the email.

5. Import the ZIP file into HAEVN using the steps above.
</Steps>

<Aside type="tip">
  Importing a ChatGPT ZIP file is a great way to get your full history into HAEVN immediately, before you start using the extension's sync feature for ongoing conversations.
</Aside>

For the exact HAEVN Markdown schema (YAML frontmatter + role delimiters), see [Reference → Data Formats](/reference/data-formats/#haevn-markdown-import-format).

## What happens during import

- Each conversation is added to your archive with its messages' original timestamps. It is marked as synced at the time of the import, its AI metadata is taken from the file only when the chat has none here yet, and it brings no embeddings. To put an archive back exactly as it was, use [`haevn restore`](/user-guide/backup-restore/)
- Attachments and images are extracted and stored in OPFS
- Existing chats are overwritten by default (use `--no-overwrite` in CLI to skip existing IDs)
- The search index is rebuilt after all conversations are imported (unless `--skip-index` in CLI)

<Aside type="caution">
  Large exports (thousands of conversations) can take several minutes to process. Keep the Options page open while the import runs.
</Aside>
